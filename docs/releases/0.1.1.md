# Yapp 0.1.1

- Refined the floating recording indicator with a dark charcoal pill, amber
  Yappman and sound bars, and smoother mouth animation.
- Filtered pause, mouse-click, keyboard-noise, and malformed non-speech labels
  so they are not inserted as dictated text.
- Published Yapp’s source under GPL-3.0-only with build instructions and CI tests.

Apple silicon · macOS 14 or later. English dictation runs entirely on-device
using the bundled Whisper base.en model. No model download is needed after installation.

Download the DMG, drag Yapp into Applications, and open it. Microphone and
Accessibility permissions are required. Existing users can replace Yapp in Applications.

Source for this build is available in the v0.1.1 tag. Third-party licenses are
included in the app bundle and preserved in the source tree.
