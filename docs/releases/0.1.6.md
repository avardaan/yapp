yapp 0.1.6 makes it easier to share useful diagnostics.

- Advanced → Diagnostics → Copy Last 10 Dictation Logs copies recent diagnostic events to the clipboard, ready to paste into a message. It replaces the Show Log window.
- Diagnostics now record which app and field type received the text, transcript length and whether the model repeated a phrase, and whether the clipboard was restored. No words, audio, or clipboard contents are logged.

Dictation remains fully offline with the bundled English model. Updates remain manual through Check for Updates….
